# Web Audio AR Chess

## Опис проєкту

**Web Audio AR Chess** — це вебзастосунок для розпізнавання ArUco-маркерів за допомогою камери смартфона. Програма працює без встановлення додаткового програмного забезпечення на смартфоні та запускається у веббраузері.

Основною ідеєю проєкту є створення універсальної платформи для настільних ігор із підтримкою доповненої реальності (Augmented Reality, AR) та аудіосупроводу.

На першому етапі реалізується система розпізнавання ArUco-маркерів словника **DICT_4X4_1000**. Надалі проєкт буде розширено підтримкою логіки настільних ігор, просторового позиціонування об'єктів, аудіовзаємодії та інших AR-компонентів.

## Поточні можливості

На поточному етапі реалізовано:

- запуск вебзастосунку;
- доступ до камери смартфона;
- відображення відеопотоку;
- модульну архітектуру застосунку;
- підготовку до інтеграції бібліотеки розпізнавання ArUco.

---

## Планована функціональність

- розпізнавання ArUco-маркерів;
- підтримка словника **DICT_4X4_1000**;
- відображення контуру маркера;
- відображення ідентифікатора (ID) маркера;
- оцінювання положення та орієнтації маркерів;
- підтримка настільних ігор;
- аудіосупровід подій;
- компоненти доповненої реальності.

## Основні програмні модулі

| Модуль | Призначення |
|---------|-------------|
| `CameraManager` | Керування камерою смартфона |
| `FrameProvider` | Отримання поточного кадру |
| `Frame` | Представлення одного кадру |
| `ArucoDetector` | Абстрактний інтерфейс розпізнавання маркерів |
| `OpenCvArucoDetector` | Реалізація розпізнавання на базі OpenCV |
| `DetectorFactory` | Створення необхідного детектора |
| `Marker` | Модель одного ArUco-маркера |
| `MarkerCollection` | Колекція знайдених маркерів |
| `Renderer` | Відображення відео та результатів розпізнавання |
| `Logger` | Ведення журналу повідомлень |

## Принципи проєктування

Під час розробки проєкту використовуються такі принципи:

- модульна архітектура;
- принцип єдиної відповідальності (Single Responsibility Principle);
- незалежність прикладної логіки від бібліотеки комп'ютерного зору;
- можливість заміни реалізації детектора без зміни інших модулів;
- поетапна інтеграція компонентів із перевіркою працездатності після кожного етапу розробки.
